# Mahesh Portfolio - HTML, CSS and Bootstrap

## Run the project

1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` directly in a browser, or use the VS Code Live Server extension.

## Files

- `index.html` - portfolio structure and Bootstrap components
- `style.css` - custom colors, typography, layouts and responsive styling
- `script.js` - footer year and mobile navigation behavior
- `assets/mahesh-profile.png` - profile photograph
- `assets/Mahesh-Resume.pdf` - downloadable resume

Bootstrap and Bootstrap Icons are loaded through CDN links, so internet access is required for their styles and icons.
